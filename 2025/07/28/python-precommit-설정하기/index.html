Python pre-commit 설정하기
25. 07. 28. / 25. 07. 28. Develop Python , Git , pre-commit , Git hooks

다른 파이썬 프로젝트를 보다가 ruff-pre-commit이 설정되었는 것을 확인해서 적용해보기로 하고, 블로그에 작업을 시작.

pre-commit

파이썬 라이브러리인 pre-commit. ~~12년된 프로젝트인데 왜 설정안했나? 나야?~~

나는 uv를 사용하니까 다음으로 설치.

uv add --dev pre-commit

dev 그룹으로 넣은건 커밋할때 빼고는 동작하지 않아도 되는걸 굳이 캐싱까지하는 CI에 넣어야하나 싶어서 이기도함.
그냥 글만 쓰게 되는 환경을 구성하게되면, 수정을 해보는걸로…

설정

pre-commit에서 사용하는 설정은 .pre-commit-config.yaml 파일에 나열 해주면된다.

repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.12.5
    hooks:
      - id: ruff-check
        args: [--fix]
      - id: ruff-format

  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v5.0.0
    hooks:
      - id: check-merge-conflict
      - id: check-toml
      - id: check-yaml
      - id: detect-private-key
      - id: end-of-file-fixer
      - id: mixed-line-ending
      - id: pretty-format-json
        args: [--autofix]
      - id: trailing-whitespace
